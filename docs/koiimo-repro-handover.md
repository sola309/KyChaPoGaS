### .aep の読み方で分かったこと
- 時刻は 24.8 固定小数 ÷ 0x7800(1/120 秒 × 256)。キーはレイヤー時間(コンポ時間 = start + t)。
- キー 1 個: 先頭 8 バイト = 時刻・補間(1 直線 2 ベジェ 3 停止)。空間でない n 次元 = 値 n・入りの速さ n・入りの影響 n・出の速さ n・出の影響 n。空間(位置・色)= 0・道のり・速さと影響 4 つ・値 n・入りの接線 n・出の接線 n。
- ldta: 104 = マットの種類(1 アルファ 2 反転)、132 = 親、160 = マットに使うレイヤー(AE 2023 の方式。真上とは限らない)、37〜39 = 旗(0x1 表示 0x200 調整 0x400 3D 0x800 モーションブラー 0x8000 ヌル)。
- **既定値のプロパティはファイルに入らない**(位置 = コンポの中心、アンカー = 箱の中心、不透明度 100 など)。静的な値は末尾の 0 が落ちる(色 ARGB の B=0 も)。
- 次元を分けていない位置でも Position_0/1 に 0 が入っている → キーか 0 以外のときだけ分けた位置とみなす。
- 点の値(ポイント制御・グラデーションの始点)はレイヤーの大きさに対する割合。
- エフェクト・シェイプの塗り/線の有効 = グループの tdsb の bit0。付け直したエフェクト名 = エフェクトの tdgp の tdsn。
- 無いエフェクトを呼ぶ式は AE でも止まって元の値になる(XYZ 位置の分割 40 か所)。
- テキスト(btdk)は鍵が番号の辞書: `/1 [ << /0 << /0 (文字)` が本文、その後ろの `/6 << /0 書体番号 /1 大きさ /5 行送り … /53 塗り [A R G B] /54 線 /57 線あり /63 線の太さ`。
