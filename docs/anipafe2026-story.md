# AniPAFE2026 ストーリーバイブル（2026-08-19 確定）

曲: Distance point / Faylan。悪魔ほむら視点。「ワルプルギスの廻天」の予想・解釈MAD。
曲名の「距離」＝まどかとほむらの間の、愛しているのに引き裂かれ続ける距離。

## 中心構造: 引き裂きの対称

```
叛逆:  アルティメットまどか = 【神性】＋【人間まどか】に引き裂かれた
                              → 神性は「円環の理の抜け殻」としてオーブに封じられる
本作:  悪魔ほむら          = 【概念(悪魔)】＋【人間ほむら】に引き裂かれる
                              → 引き裂くのは【まどかの矢】(C51-54→C55)
       ワルプルギスの夜     = まどかの抜け殻 × ほむらの概念 の融合体
                              → 地上には人間まどかと人間ほむらが残る
```

「また躰 引き裂くまで」の「また」= まどかに起きた引き裂きがほむらにも反復されること。
C6(TV版ワルプルギス)は第1幕に置き、C55-56での再来を効かせる布石。

## 確定事項（ユーザー回答 2026-08-19）

1. **C55の引き金はまどかの矢**。まどかが引き裂いた側になる。C58の涙はその重さを背負う
2. **ワルプルギス＝抜け殻×概念の融合**で確定
3. **C60「糸が切れる」= いつかループが終わる希望**。ただし「終わらせることは信条を
   度外視すれば可能」というだけであり、**全登場人物にとって最良とは限らない**。
   希望と引き換えの喪失を含む、両義的なトーンで描く
4. **間奏C36-43は前後半に分かれる**（間奏の途中で転調がある）:
   - 前半: 廻天新キャラ（セルマ・紫丁香）の受け皿
   - 後半: 戦闘的な展開部（侵攻/暴走）
5. **C61-65 = 走馬灯 ＋ まだ見ぬ可能性**。歴代ループの記憶と、いつか起きるかもしれない
   未来の断片。**不確実性を残す**（結末を断定する画にしない）
6. **なぎさ＝円環の理の使者**（叛逆と同じ役回り）。C20・C29に登場

## モチーフの3本糸

- **糸(因果)**: C1絡まる → C2回収 → C32-33操る → C45逆転(ほむらが絡まる) → **C60切れる(両義的な希望)**
- **裂け目**: C18半月(最初から欠けた世界) → C19-20(2人の亀裂・反射) → C23キービジュアル → C50オーブ割れ → **C55引き裂き**
- **災厄の再来**: C6顕現(TV) → C55-56(ほむら自身がワルプルギスとして再来)

## 制作上の含意

- C51-54(構え3連)は「撃つ側の重さ」の等級上げ。C52の涙は**これから自分が引き裂く**ことへの涙
- C57-58(涙の対)は「引き裂かれた者」と「引き裂いた者」の対
- C68はC1のオーブに糸が絡まり始める画に戻る(承認済みの提案)
- キュゥべえは表情厳守(名簿note参照)。なぎさの使者性はC20で「最前列に立つ」ことで示す
