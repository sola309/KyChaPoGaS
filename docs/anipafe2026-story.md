## 中心構造: 引き裂きの対称

```
叛逆:  アルティメットまどか = 【神性】＋【人間まどか】に引き裂かれた
                              → 神性は「円環の理の抜け殻」としてオーブに封じられる
本作:  悪魔ほむら          = 【概念(悪魔)】＋【人間ほむら】に引き裂かれる
                              → 引き裂くのは【まどかの矢】(C50-53→C54)
       ワルプルギスの夜     = まどかの抜け殻 × ほむらの概念 の融合体
                              → 地上には人間まどかと人間ほむらが残る
```

「また躰 引き裂くまで」の「また」= まどかに起きた引き裂きがほむらにも反復されること。
C6(TV版ワルプルギス)は第1幕に置き、C54-55での再来を効かせる布石。

## ★ 稼働する残骸（2026-08-22 ユーザー提案・採用）

**アルティメットまどかの残骸は、意志を失ったまま「円環の理の機能」だけを維持して稼働し続けている。**

- だから廻天の世界には**魔獣が存在する**（魔女化を回収する機能だけは生きている）
- 残骸はダークオーブの中身そのもの。C1で糸が絡まっていくのは、
  **残骸が処理し続けている因果が溜まっていく**姿
- **その残骸にエラーが起きる**ことが後半の駆動力であり、
  C49オーブ割れ／C54引き裂き／ワルプルギス顕現の因果的な土台になる

これが埋めた穴:
1. 廻天世界に魔獣がいる理由が、本作の中だけで自足する
2. **「なぜ今なのか」**が説明できる。引き裂きは遠い昔に起き、亀裂はいま初めて表面化する
   → 『流れた月日にいま亀裂が見えたよ』そのもの
3. 残骸=**第一の裂け目**。以後の裂け目(半月・まどか・オーブ・ほむら)はすべてその反復になる
4. C1とC20が「同じ事象の別スケール」になり、円環構造が閉じる

### 残骸は二つに分かれている（2026-08-22 確定）

| | 空の紋章石 | ダークオーブ |
|---|---|---|
| 中身 | 残骸の**外側=機能** | 残骸の**内側=意志** |
| 状態 | 意志を失ったまま**稼働し続けている** | ほむらが引き剥がして封じた |
| 効果 | だから廻天世界に**魔獣がいる** | だからほむらは何も救えていない |
| ほむらとの関係 | **手が届かない**。見ることすらできない | 手の中にある |

**エラーは「意志を失ったまま動く外側」から始まる。** ほむらが手を出せない領域に事件の源が
あることで、後半が彼女の自作自演にならずに済む。C20で彼女が座り込むのは諦めではなく**無力**。

出典: 叛逆ラストの見滝原の空に浮かぶ、円環の理の紋章を刻んだ石状の物体。
**空に映るはずのない影**が落ちており、世界を外側から観測する装置の外殻に見える。

### ★ ほむらの権能とその唯一の穴（2026-08-22 確定）

**ほむらは悪魔の権能で宇宙そのものを改変しており、基本的にできないことは無い。**
叛逆のような閉じた仮想世界ではなく、**現実の宇宙が書き換えられている**。世界は一つ。

⚠ 誤り訂正: 「偽街と現実を分ける」「完全な月すら作れない能力不足」はいずれも誤読。
ほむらを過小評価した解釈で、2026-08-22にユーザーが却下。

**唯一の穴は、まどかに関わるものだけが制御できないブラックボックスであること。**

### ★ 半月＝上書きの失敗した紋章石（2026-08-22 採用・確定）

原作に半月と紋章石が同居するカットが存在しないことへの解: **同じ物体だから。**

- 紋章石はまどかの残骸 = 彼女のブラックボックス。**改変できない唯一の物**
- ほむらは宇宙を書き換える際、それを**上書きで覆い隠した**。内側から見れば空には月がある
- だが上書きが効いたのは**まどかに属さない半分だけ**。もう半分は書き換えを弾いた
- 従って **半月の「まっすぐな切断面」＝ 彼女の権能が及ぶ境界線そのもの**

得られるもの:
1. 能力不足ではなく**権能の限界の可視化**になる。しかも限界はまどかにだけ現れる
2. 両者が同居しないのは同じ物体だから ── 世界を分けずに制約を満たす
3. **光源のない影**の説明がつく。月は表面の上書き、影を落としているのは下の実体(石)
4. 上書きが完全に剥がれるとき(C49オーブ割れ/C54)、月がめくれて石が現れる = 一度きりの payoff
5. 裂け目モチーフの起点が「彼女が触れられなかった線」になり、C54で自分が裂かれることに反転する

### ★ 光源のない影 — 全編を通す隠しモチーフ（2026-08-22 確定）

光源の説明がつかない影が、全編を通して随所に落ちる(地面・壁・人物・水面)。
観客は繰り返し目にし、終盤で「**外側に何かある**」と分かる。説明台詞なしで世界観を仕込む装置。

- 形は紋章の輪郭に**寄せすぎない**。丸い縁と放射の気配だけ
- 偽街のカットでは、映らない紋章石の影として機能する
- 現実のカットでは、石そのものと影の両方が見える

**裂け目モチーフの改訂**:

→ C49オーブ割れ(エラー完成) → **C54引き裂き**

# ★★ 全体構造の確定（2026-08-23）— 閉じた因果の環

## 中核の仮説（ユーザー提案・採用）

**ワルプルギスの夜 ＝ まどかの概念(神) × ほむらの概念(悪魔) の融合体。**

1. 由来が二人にあるからこそ、**他の魔法少女には倒せず、まどかだけが倒せる**
   (TV版で誰も倒せなかった事実と整合する)
2. 廻天の世界は**魔獣の世界**であり、魔女であるワルプルギスは本来顕現しない
3. それが顕現し、**宇宙を一巡させる規模のタイムリープ**を行う
4. **その結果がTV版・劇場版に現れるワルプルギスの夜である**

→ 原因が結果の後に来る**閉じた環**。本作の終わりが、シリーズの始まりを作る。

## キュゥべえの動機（採用）

**魔女の時代を取り戻すこと。**

- 円環以後、彼が得るのは魔獣由来の効率の悪いエネルギーだけ
- 円環がある限り魔女は生まれない
- **例外は円環の管理外にある二つの概念(神と悪魔)だけ**
- 彼はその**融合を仕組む**
- 生まれたワルプルギスが宇宙を一巡させれば、魔女のいた時代に戻る

**そしてTV版の彼が異様に落ち着いているのは、既に一度これをやったから。**
C11(円環の阻止)からC34(誘うFake eyes)まで、彼の行動は最初から一貫している。

## ほむらの動機と手段（確定）

**⚠ 悪魔ほむらに時間操作能力は無い**(願いが「まどかとの出会いをやり直したい」であり、
宇宙改変後に能力を失って弓に転じた)。目的も「やり直し」ではなく
**「まどかに人間のまま生きてほしい」**。

**では、なぜC58以降でタイムリープするのか:**

- ワルプルギスは**まどかの神性を連れて**過去へ去る
- 人間ほむらは気づく ── **過去でワルプルギスが見滝原を襲い、まどかはまた願い、また神になり、また引き裂かれる**
- 彼女が追うのは**やり直すためではなく、循環を止めるため**
- 追う力は無い。**しかしキュゥべえがそこにいる**
- 彼女は契約する。願いは **「まどかとの出会いをやり直したい」** ＝ TV版のあの願い

**キュゥべえは二重に勝つ**: 魔女の時代を取り戻し、かつ最も効率の良い魔法少女を1人得る。

## 本作で最も残酷な帰結

**TV版のほむらが何百回もループして戦い続けている相手は、彼女とまどかがなったものである。**

倒せるわけがない。自分自身だから。倒せるのはまどかだけ ── **自分の半分が入っているから**。
そして彼女はそれを**知らないまま**永遠に戦い続ける。

## 皮肉の完成

神性が去ったことで、まどかは**完全な人間**になる。
**ほむらの望みは叶う。** そして彼女は、叶ったからこそ追いかける。
→ 「We know the hell when you get my real love」の最終的な回収。

## 三分割の対称（確定）

| | 人間 | 意志 | **意志なく動き続ける機能** |
|---|---|---|---|
| **まどか** | 人間まどか | ダークオーブの中身 | **空の紋章石**(魔獣が存在する理由) |
| **ほむら** | 人間ほむら | 悪魔の概念 | **クララドールズ**(命令なしに動く罪) |

引き裂きの回数も対称:
- **まどかは2回**: 神性/人間(叛逆) → 神性がさらに 意志/機能(ほむらが封じた)
- **ほむらも2回**: 自己/クララドールズ(C18・**自らの絶望で**) → 概念/人間(C54・**まどかの矢で**)

**ほむらがまどかを2回裂き、まどかがほむらを1回裂く。残る1回は自分で自分を裂いた。**
その非対称の一点が、彼女の孤独。

⚠ 撤回: 「クララドールズ＝ループの数」は誤り。ほむらのループ回数は桁違いに多い。
