## 4. 全素材共通の生成規約(撮影処理)

- **カラースクリプトのブロック値を厳守**(基調3色/キー光の方向/黒占有)
- LIGHT/LENS共通ブロックを幕ごとに固定(検証済みの撮影設計方式)。
  シネマティックの実装は**光の物理**で書く: 光源の位置と色/返しの有無/黒の占有率/
  面ごとの大気(近中遠で靄とコントラスト差)/最も明るい要素だけブルーム
- 品質語(cinematic/masterpiece等)は書かない。**記述された振る舞いだけが効く**
- 参照には役割宣言(`subject definition only, not a target frame` 等)
- 設定資料の枠・パネル・寸法・文字は出力しない指示を必ず添える
- 否定は様式分類のみ。内容の排除は肯定形の代替で書く
