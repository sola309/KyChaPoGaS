# AniPAFE2026 演出原則（2026-08-22 制定）

「直接的な表現だけだと映像が薄っぺらくなる」というユーザー指摘への恒久対処。
全67カットの設計・レビューは**この4原則を基準**に行う。要素チェック(ワイプが出た/キャラが出た)は
前提条件であって合格基準ではない。

---

## 原則1: 示唆で語る — 説明する要素を1つ削る

**結果を見せて、原因は見せない。人ではなく物を見せる。最中ではなく直後を見せる。**

| 直接的(避ける) | 示唆的(採る) |
|---|---|
| ほむらが人形を生み出す | 落ちた**羽根が地面に触れた瞬間、それは人形の手**になっている |
| まどかが悲しんでいる顔 | **持ち上げかけて下ろした手**。顔は見せない |
| 世界が壊れる | **水面の反射だけが割れている**。実物は無傷 |
| 時間が巻き戻る | 同じ**紅茶が2度注がれる**。人物は映さない |
| ほむらが無力だ | 見上げない。**見上げても何も無いから** |

**設計手順**: カットを書いたら「これは何を説明しているか」を列挙し、**最も直接的な1つを消す**。
消した分の尺は「観客が繋げる間」に使う。

**ただし全カットを示唆にしない。** 示唆が続くと観客は疲れて意味を追うのをやめる。
**ブロックに1つは直球のカット**を置き、そこを支点にする(例: C22キービジュアル)。

## 原則2: 緩急 — 人物のいないカットを設計に組み込む

全カットに人物がいると、目が休まらず**全部が同じ重さ**になって、結果的に何も残らない。

**目標: 67カット中 10〜14カット(15〜20%)を「人物なし」にする。**

| 種別 | 中身 | 役割 |
|---|---|---|
| **物のインサート** | 落ちた羽根 / 割れた宝石 / 空の椅子 / 砂 / 紅茶 / 靴 | 直前のカットの意味を確定させる。1〜2秒 |
| **背景のみ** | 空 / 地形 / 街 / 水面 | 呼吸。次の高密度への助走 |
| **抽象・幾何** | 円環 / 直線の切断 / 糸の交差 | モチーフの提示。編集のリズム点 |

**配置の原則**: 高密度カットの**直後**に置く(直前ではない)。衝撃の残響として機能させる。

**人物なしカットは「静」ではない。** 物が動いてよい(羽根が落ちる/砂が流れる)。
止めるのは**カメラと編集**であって被写体ではない。

## 原則3: AI特有の映像技術を意図的に使う

手描きアニメの模倣に留めない。**AIでしか出せない画**を武器にする。ただし装飾ではなく
**意味に紐づいたときだけ**使う。

| 技術 | 内容 | 本作での意味づけ |
|---|---|---|
| **material morph** | 物質が別の物質へ連続変化 | 羽根→人形(罪の発生) / 砂→ガラス |
| **semantic morph** | 意味が別の意味へ変化 | まどかの弓→円環の紋章 |
| **occlusion handoff** | 手前を通る物の陰でカットが入れ替わる | 場面転換の主力。カットを感じさせない |
| **dissolution** | 輪郭が粒子へ解けていく | 儚さ・消滅。C56-57の涙 |
| **datamosh** | 前カットのブロックが次へ滲み出す | 記憶の混線。走馬灯(C60-64) |
| **scanline tear / displacement** | 画面が水平にずれる | **上書きの失敗**。紋章石まわりで使う |
| **reflection inversion** | 反射だけが実物と違う | 「壊れているのは世界でなく見え方」 |
| **silhouette window** | 人物の輪郭の内側に別の画 | 文字窓の代替(文字禁止のため)。窓の中身は必ず歌詞が指すもの |
| **時間の非対称** | 背景と人物で時間の流れが違う | 影だけが逆に流れる等 |

**禁止**: 意味の無いグリッチ、音と無関係な装飾的モーション、品質語による誤魔化し。

## 原則4: フル尺(4分24秒)で飽きさせない構造

### 4-1 密度の変調
全ブロックを最大密度にしない。カラースクリプトの「動きのテンポ」欄に従い、
**密→疎→密**の波を作る。疎のブロックがあるから密が効く。

### 4-2 規則を作り、終盤で破る
本作が持つ規則と、その破り方:

| 規則 | 破る場所 | 効果 |
|---|---|---|
| 半月と紋章石は同居しない | 上書きが剥がれる瞬間(C49/C54) | 一度きりの衝撃 |
| 光源のない影がある | 影の主が現れる終盤 | 全編の伏線が回収される |
| 赤はモチーフ専用(糸・宝石・眼) | C50-54で赤の面積が増える | 進行そのものを色で語る |
| 人物なしカットは呼吸 | 終盤の人物なしカットが**最も重い**(C67) | 意味が反転する |

### 4-3 反復と変奏
同じ画を**3回**繰り返し、3回目だけ変える(C1 → C31-32 → C67 のオーブと糸)。
2回では反復と気づかれず、4回では飽きる。

### 4-4 一目で分かる差別化
キャラ別カラー(まどか=桃 / ほむら=紫黒+赤 / さやか=青 / 杏子=紅 / マミ=金 / なぎさ=橙)を全編固定。
高速カットでも誰が出たか読める。

## レビュー基準（カットごとに問う4項目）

1. **示唆**: このカットが説明しすぎている要素は無いか。1つ削れないか
2. **緩急**: 直前・直後との対比があるか。同じ重さのカットが3つ続いていないか
3. **技術**: このカットのAI技術は意味に紐づいているか。装飾になっていないか
4. **一貫**: モチーフ3本糸・キャラ色・パレット・影の規則から外れていないか
