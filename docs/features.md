# KyChaPoGaS 実装機能一覧

最終更新: 2026-07-07。UIの📖リファレンスタブとAI(`get_agent_guide`)から参照される。

## 🎬 編集(タイムラインNLE)
- ビート同期タイムライン: 波形/ビートグリッド/リズムレーン/シーンマーカー/速度カーブ
- クリップ操作: 分割・移動・トリム・速度・トランジション・音量フェード・AE風トランスフォーム
- 自動編集: ビートへの自動カット(auto_cut_to_beats)、拍エフェクト散布(scatter_beat_effects)、音ハメスコア
- プレビュー: 全トラック合成表示・軽量/高画質切替・ガイド枠・📷キーフレーム抽出
- **🔍差分再生モード**: フレーム間差分の可視化+動き量数値+スパークライン(カット/モーション量の検証)
- クリップのフィルムストリップ表示(常に16:9タイル)
- 書き出し: 高品質レンダ(crf16/lanczos/多段再エンコ対策)

## 🤖 AIモード
- チャット主導編集: タイムライン編集・解析・生成ジョブの全ツール(25種)を言葉で指示
- ローカルLLM対応: Anthropicキーなしでも Nemotron(ollama) がツールを実行
- MCPサーバー: Claude Code等の外部エージェントから同じツールを利用可

## 🎞 ショット(タイムライン起点生成)
- 画像@再生位置: アセット挿入 / t2i / **i2i(参照=再生位置のVideoフレーム or アセット、変化量denoise指定)** / **✏️AI編集(指示文編集: Qwen-Edit-2511 / HiDream-O1 / FLUX.2 klein KV、参照最大3枚)** / **🎥Vフレーム(動画アセット→フィルムストリップ+コマ送りでフレーム選択→長辺px指定(lanczos拡縮)で挿入)** → Imageトラックへ自動配置
- **範囲指定i2v**: 開始/終了フレームで長さを規定、Imageトラックのキーフレームを検出して
  1枚=I2V / 端2枚=FLF2V / 中間あり=VACE を自動選択 → Shotsトラックへ自動配置
- 生成ジョブの`place`パラメータ: 完成時にタイムラインへ自動配置(画像/動画共通)、`replace_clip_id`で差し替え
- **選択KF→i2v**: Imageトラックのピンをタップで複数選択(①②③)→「🎬選択KF→i2v」。キーフレーム=ピン左端の◆打点。2枚=FLF2V/3枚以上=VACE、範囲は最初→最後の打点で自動。連続ショットは境界画像1枚を共有
- クリップ選択→「🔁再生成」: 生成時の条件(prompt/seed/変化量)を微修正して同位置に差し替え

## 🖼 画像生成
- SDXL系アニメ(WAI Illustrious/Animagine/NoobAI)・Krea2(自然文)
- LoRA適用/学習(🧪LoRA Lab: キャラ・衣装スロット8種)

## 🧊 3D生成・3Dカメラ
- 画像→3Dモデル: オブジェクト(Hunyuan3D-2, 単/4面マルチビュー)・シーン起伏(MoGe-2, 3Dフォト)
- GLB→透過webm焼き出し(ターンテーブル/ドリー/アーク/スウェイ/パララックス × トゥーン/標準/ワイヤ)
- **🎬AIレンダ動画(3dcam)**: 3Dシーン(複数GLB配置)+カメラキーフレーム→深度→Wan2.2 Fun Controlで原画品質動画
- ビートカメラ: ビート同期カメラキー自動生成(パンチイン/回り込み/揺れ/ライザー)
- 🎛カメラグラフエディタ: キーフレームをカーブで可視化・ドラッグ調整・ease指定

## 🎬 動画生成
- Wan2.2: FLF2V(最初/最後フレーム)・**VACE(任意位置キーフレーム1パス固定・Refトラックの時刻反映)**・Fun-InP・S2V(歌唱/口パク)・Fun Control(深度制御)
- 高速化: lightx2v 1022蒸留LoRA(4step/cfg1/shift5, 従来比≈10x)標準ON
- SVD-XT、フレーム補間(RIFE系)、VLMレビュー(破綻自動チェック)

## 🎵 音楽(Music Studio)
- ACE-Step 1.5 XL(4B)生成: caption/構造タグ歌詞/BPM/キー指定、バリアント一括
- 🩺譜割りチェック(mora linter: 字数パターン/BPM密度/助詞終わり検査)
- 歌詞一致検査(adherence: ボーカル分離+ASRで反復/脱落検出)
- 曲解析(punch/energy弧/取りやすさ)・区間リペイント・構成シート(章割り→shotlist雛形)
- ステム分離(drums/bass/vocal/other 30Hzエンベロープ→モーション駆動)

## 📝 MADビルダー(mad-kit)
- shotlist.json宣言型: テンプレ18種・FX8種・enter/idle/ambient/グレード/ステム反応
- scene3d: GLBを実3Dカメラで撮影(複数体配置+キーフレームカメラ)
- ショットエディタ: ショット単位のプロキシ再生成・自然言語編集(instruct)・テイク比較
- import_to_app: ショットをタイムラインへクリップ配置(タイムライン第一原則)
- final: 1080p60レンダ+音マックス+カット↔ビート一致検証

## 🎎 リグスタジオ
- レイヤー順序修正(↑↓/表示切替)・揺れモノ設定(タイプ/ピン先/強さ/**ピン位置pinY**)
- 口・目差分の位置/スケール調整(プレビュー即時反映)・口パク/表情テスト
- レイヤー微修正ブラシ(消す/元画像から戻す筆)
- **モーションエディタ**: 首/頷/口パク/声量の4トラックをキーフレームで設計→透過webmクリップ生成
- レイヤーPSD書き出し(外部エディタ用, /api/puppet/{pid}/rig25d.psd)
