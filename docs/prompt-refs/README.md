# 参考プロンプト集

ユーザーが「これは良い映像が出た」と持ち込んだプロンプトを、**原文のまま**保存し、
本作(MiniMax H3)へ移植できる要素だけを抜き出して記録する場所。

## 運用ルール

1. 1件 = 1ファイル `NNN-短い名前.md`。原文は改変せずそのまま貼る
   (要約すると後から検証できなくなる。書き方の細部にこそ効きめがある)
2. 出所のモデル/プラットフォームを推定して書く。記法が違えば移植には翻訳が要る
3. **採用可否は必ず「本作の実測」と突き合わせて書く**。他所で効いた書き方が
   H3でも効くとは限らない(例: 否定文。H3では実測で逆効果になった事例がある)
4. 採用した要素は `docs/h3-prompt-writing.md` 側にも反映し、ここは出所の記録に徹する
