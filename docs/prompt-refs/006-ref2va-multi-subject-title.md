## ★★★ 「なぎさが弓を持つ」不具合の直接の対処法

```
Never merge the three characters.
Never exchange their hair, eyes, clothing, accessories, or facial features.
```

本作でまさに起きた事故(#2871まどかの弓がなぎさへ転写された)への**専用の一文**。
参照が複数人ぶんあるとき、モデルは属性を混ぜる。それを1行で禁じている。

本作の実測「内容の否定は逆効果」との関係: これは**視覚要素の存在の否定ではなく、
同一性の混同という失敗モードの禁止**。カテゴリが違うので採用してよいと判断する
(要検証だが、この作例では成立している)。

## ★★ retention marker を「1参照につき2つ」使う

```
<Subject 1>: fully_preserved identity and wardrobe; partially_preserved original environment.
<Subject 2>: fully_preserved identity, hood, eyes, scarf, and tactical costume; weak_reference for background.
```

**同一性は `fully_preserved`、背景は `partially_preserved` / `weak_reference`** と、
1つの参照画像を**属性ごとに違うマーカーで扱っている**。

本作は1参照につき1マーカーしか書いていなかった(全部 `partially_preserved`)。
「デザインは完全に保ち、ボードの背景は捨てる」を明示できていなかった。

## ★★ `attribute_transfer` は「スタイル」に使う

```
The shared anime rendering, hard shadows, black-red palette, and nocturnal atmosphere are attribute_transfer.
```

**物体ではなく、画風・影・パレット・空気感に対して**使っている。これが本来の用法。
本作のピンは design アセットに `attribute_transfer` を付けており、
「別被写体への転写=誤用注意」と自分で書いていたのに、正しい使い方を知らなかった。

## ★★ 複数の被写体を1枚の参照で定義できる

```
<Subject 3> consists of the hooded woman and the tan cat in reference image 3.
Preserve the woman's exact side profile ... and her eye line toward the cat.
Preserve the cat's appearance, collar, scale, position, and eye line.
```

1枚の参照に2体いる場合、**関係(視線・相対スケール・位置)ごと保存させられる**。

→ 本作のキャストプレート(#2892, 4人並び)は、
`<Subject N> consists of the four girls in reference image N` として、
**各人の識別特徴と相対身長を Preserve リストで書く**のが正しい。
私は「FIRST/SECOND/THIRD/FOURTH figure」と散文で書いていた。

## ★ Preserve リスト方式

```
Preserve her exact face, profile, hairstyle, earrings, hands, clothing, cigarette, and composed hard-boiled expression.
```

外見の**描写**の後に、**何が保たれるべきかのチェックリスト**を付ける。
描写と保存指示を分けているのが要点。

## ★ Z順を「体の部位」を基準に3層で指定

```
large cropped letters ... move slowly BEHIND HER HEAD,
while smaller red typographic coordinates move IN FRONT OF the distant background
but remain BEHIND HER HAND AND CIGARETTE.
```

本作は「キャラは雲より前」程度しか書いていなかった。
**部位を基準にすると層が確定する**(頭の後ろ/手の前/背景の前)。

## ★ 危険な失敗モードは「そのショットの中」で禁じる

```
[Shot 3] ... No facial deformation, duplicate eyes, costume changes, or uncontrolled digital glitch.
```

グローバルなAVOIDではなく、**リスクが発生するショットの末尾**に置いている。
顔に寄るショットだから顔の破綻を、そこで禁じる。
