   Ref2VAでもこの役割を与えれば I2V と同じ挙動になる

## 1. タイポグラフィ

**使わない。C3のロゴのみが唯一の例外**（憲法30条）。C3も「文字を書かせる」のではなく
**参照からロゴを図形として複製**する（`fully_preserved`／T1で日本語の字形保持を確認済み）。

文字を封じたぶんの代替が **キャラシルエット窓**（人物の輪郭の内側に別の画）。
MG言語辞書で「文字窓の代替の**主役**」と定義しながら4箇所しか使っていなかった。
**窓の中身は必ずその歌詞が指すもの**にする。窓の形自体（半月形・亀裂形）が本作のモチーフ。

## 3. I2VA と Ref2VA

**既定は Ref2VA。** 参照の既定役割は
`(reference role: subject definition only, not a target frame and not a storyboard anchor)`。

**I2VAは3条件を全て満たすときだけ**: ①単一カット ②承認構図そのものが出る必要がある
③価値がその1枚の保持・変質にある。

| 単位 | カット | 理由 |
|---|---|---|
| U01 | C1 半月 | 全編の起点。動くのは影だけ |
| U06 | C7 水面 | 設計に「#2944をそのまま」と明記 |
| U10 | C11 水面2段目 | C7と同構図でなければ変奏が読めない |
| U42 | C67 回帰 | C1と画が一致することが円環の成立条件 |

現状 I2VA 8 / anchor 24 → **I2VA 4〜6 / anchor 0〜4**。
公式は「新規の芝居・背景・出来事は忠実性の欠損ではない。自由解釈は想定内」と明記している。

## 4. 音合わせ — 解析データを制御可能な全箇所で使い切る

**ショット枠を大量に余らせていた: 現在67ショット / スネアに乗せられる枠は261。**

制御精度の実測:

| | 精度 |
|---|---|
| ショット内の拍ヒット | でたらめと区別がつかない |
| **ショット境界 `[Shot N] At MM:SS.mmm`** | **誤差0.4〜1.1フレーム** |

**MGにおいてワイプもパネル切替もショット境界である。** ゆえにMGイベントを
`[Shot N]` に変換すれば、制御不能だったものが制御可能になる。

- **層1 生成**: スネアの実測時刻に `[Shot N]` を打つ。MG主戦場は**6〜9ショット**、
  各ショット**0.5秒以上**。⚠実測で9カット詰めると間引きが起きたため、**T1で限界を実測してから確定**
- **層2 生成音**: キック=衝撃 / シンバル=光と粒子。**画面内の物**に鳴らせる（映像と音は同時生成）
- **層3 オーバーレイMG**: MGエンジン（Pixi.js+GSAP・決定論キャプチャ）で**打点時刻へ数値で打ち込む**。
  ここはフレーム完全一致。生成に祈らない

### 手動盛り上げ（5区間・面で使う）

C2(8.67-11.00) / C7(37.50-38.67) / C16・C17(73.29-77.92) / C46(187.21-189.54) / C53(205.67-208.00)。
いずれも**「次に何かが始まる」直前**。打点が「点」で刻むのに対し、盛り上げは**「面」で膨らませる**:
- 生成: 区間の頭から終わりへ**一方向に増える量**を1つ割り当てる
- MG: 区間で**連続量を補間**（帯の速度・分割数・糸の張力・ブルーム強度）
- 編集: 尺配分の根拠

## 6. シネマティックなライティング — 全カット。MGと共存する

**「MGか光か」は誤った二分法だった（訂正）。** ノワール001が本作の環境で成立したのは、
あれが**エディトリアルMGとノワールの光の両方**だったから。002も008も同じ。

**共存の仕組み — 層が違う:**

| | 担当 |
|---|---|
| MG | 構成と転換（パネル・マスク・ワイプ・Z順・分割・窓） |
| ライティング | 各面の中身と全体の階調 |

**MG要素はそれ自体が光を受ける物体。** 既存規則（トランジションは実在の物体として書く）の
必然的な帰結。光があるからMGが「板」でなく「物」になる。**光の欠如こそが安っぽさの原因。**

組み合わせの規則:
1. **MG要素を光源系に組み込む** — パネルの縁がスペキュラを拾う／**窓の内と外で光の質が変わる**
   （窓の中は別の世界だから別の光）／羽根の群れは一枚ずつリムを持つ
2. **MGの面 = `{{DEPTH}}` の深度面** — 5〜8枚がそのままパネルの層。面ごとに減衰と大気が違う
3. **黒の占有が両方を助ける** — 黒が半分あるからグラフィックの縁も光も立つ
4. ⚠ **撮影パスはMGにも掛ける** — オーバーレイMGを**グレードの前に合成**しないと、
   グレインもビネットも掛からず貼り付けたステッカーに見える。**レンダ順の確認が必要**

3層構造は維持: 幕別スタイルブロック（全カット共通の土台）／決定論の撮影パス（100%）／
ライティングを主役にするカット（打点ゼロの11本。MGを置かない11本と一致）。

## 7. 書き直しの手順

1. `storyboard anchor` 24箇所を `subject definition only` へ（機械的）
2. I2VA 8 → 4〜6（U01/U06/U10/U42 を残し他は Ref2VA へ）
3. **T1でショット密度の限界を実測**（U27で6ショット版と10ショット版を比較・約20分）
4. 各単位に **MG辞書から最低1つの技法を意味付きで配置**（演出原則3に従い装飾にしない）
5. スネア実測時刻を `[Shot N] At MM:SS.mmm` へ展開
6. 盛り上げ5区間に**連続量**を割り当て
7. 光は**削らない**。MG要素にも光を与える
8. lint → T1全数 → 通しで確認
