## 1. 共通MG辞書（全編で共通の語彙）

ストーリーバイブルの**モチーフ3本糸**にMG要素を1対1で括り付ける。
物語の糸が画面処理の糸でもある、という一貫。

| モチーフ糸 | 窓(マスク) | ワイプ/トランジション | 由来 |
|---|---|---|---|
| **糸(因果)** | 絡まる糸の隙間が窓になる | **ピンクの糸が画面を横切り、通過跡が次の画** | C1絡まる→C59切れる |
| **裂け目** | **半月形・亀裂形の窓**(C17の半月と同じ「切られた」形) | **亀裂が走り、割れ目から次の画** | C17半月→C54引き裂き |
| **災厄/嵐** | 砂時計の輪郭(ほむらの盾)・円環 | **黄金の嵐光の帯**・**黒羽根の群れ**が画面を拭う | #2872黄金嵐・悪魔の翼 |

**キャラシルエット窓**: 文字窓の代替の主役。人物の輪郭の内側に別の画(過去/心象/対になる人物)が
覗く。「窓の中の画」は必ず**その歌詞が指すもの**にする。

**キャラ別カラー**(原作設定と一致・全編固定):
まどか=桃 / ほむら=紫黒+赤 / さやか=青 / 杏子=紅 / マミ=金 / なぎさ=橙 / キュゥべえ=白+赤目

**打点→映像のルール**(時刻は書かない。関係だけを全編で固定):
- スネア → ハードカット または 窓の切替
- キック → 身体・物体の衝撃(踏込/着地/衝突)
- シンバル → 光と粒子の炸裂(燠火/羽根/花びら)
- **画面内の物が音を出すように書く**(H3は映像と音を同時生成するため同期が自然に出る):
  羽根が裂ける音、人形の関節の軋み、砂が岩を打つ音、弓弦、泡の破裂。
  楽曲への正確な位置合わせは**⏱時間リマップ**の仕事

**全編共通の様式ラベル**(Shot 1冒頭に1回だけ・本文に品質語を散らさない):
`2D Japanese cel animation × editorial motion-graphic composition. Hard-edge cel shading,
1-2 shadow layers. Every frame reads as a theatrical key visual.`

**禁則**: 文字・数字・ロゴ・擬似文字は全面禁止(NO-TEXT RULE形式で列挙)。
キュゥべえは無表情。否定は様式カテゴリのみ。

## 3. サビ1ブロック設計（C17-C22 / f1814-2256 / 77.9-94.0s）

### C17 (2.33s) — 半月世界【サビ前最後の1拍】
- **歌詞**: (ブレス) / **役割**: 裂け目モチーフの原型提示。C22キービジュアルへの伏線
- **画**: 欠けた月が浮かぶ偽街の空。**月の欠け際=最初の「切られた形」**を正面から見せる静のカット
- **MGルール**: 動きは月へ吸い込まれる薄雲のみ。**末尾6フレームで月の欠け際が鋭く発光**し、
  その光の線がC18頭の「指の間の光」に**位置とアングルで繋がる**(マッチカット)
- **実尺の書き方**: 2.3秒で全て。「静止した一枚絵+末尾の発光」のみ
- **参照計画**: 半月世界の環境画(要素材) / **素材**: 半月の偽街空 1枚(承認ゲート対象)

### C18 (4.29s) — 絶望から罪が生まれた
- **画**: 検証済みのjob 3592構成を土台に、**「罪の誕生」を窓で語る**:
  ほむらの手が開く→指の間から光→**嵐の光が『ほむらのシルエット窓』になり、
  窓の中で羽根が人形に変わる**→窓が割れて人形が実体として飛び出す
  (羽根→人形の変換=intentどおり。窓が「絶望の内側から罪が生まれる」の視覚文)
- **MGルール**: `Her opening hand triggers…` `Snare hits trigger hard cuts` `Cymbals trigger
  ember bursts` / 人形は近景=逆光シルエット・遠景=模様
- **音**: 羽根の裂ける音、人形の関節の軋み(画面内フォーリー)
- **参照計画**: #2610ほむら(顔・衣装) / #2605人形(デザイン) / #2872嵐(世界)。役割宣言+
  「ボードの枠・パネルは出力しない」明記 / **素材**: 追加なし(検証済みの3枚)

### C19 (4.92s) — また躰 引き裂くまで
- **画**: 5人の対峙。**1本の連続前進(奥行きの深度で人物が切り替わる)は維持**しつつ、
  各人の見せ場を**「裂き」の変奏**にする:
  さやか=居合(画面が**斜めに裂けて**次の深度へ) / 杏子=槍が**鎖節に裂けて**鞭になる /
  マミ=マスケットの一斉召喚(銃列の**縦縞が縦ワイプ**) / なぎさ=泡(**球面の窓**、中の像は上下反転)

  全員の動作で反復)
- **音**: 刀の鞘鳴り、鎖の走る音、銃列の着地、泡の破裂、弓弦は鳴らさない(まどかは構えない)
- **参照計画**: 3592方式+キャストプレート#2892(4人の顔・相対身長) / 武器は名簿正典

## 5. 抽象様式の語彙（2026-08-23 追加 / 名簿 `style_study` #3141-3143）

口元プレートの生成失敗から偶発的に得た3点。参照を外したH3が同一性の錨を失って自由解釈した結果で、
狙って作ったものではない。**様式参照(weak_reference)専用** — キャラの同一性には決して使わない。

### 系譜（何と呼ばれる表現か）

| 呼び名 | 内容 | 本作との関係 |
|---|---|---|
| **劇団イヌカレー(魔女結界)** | 切り抜き・貼り絵・異物混在・読めない記号 | **原作自身の視覚言語。**カラースクリプトC55-56に既に「イヌカレーMAX」と明記済 |
| **カットアウト・コラージュ** | 切った紙を動かす(シュヴァンクマイエル/ギリアム/ライニガー) | 上記の技法的な祖 |
| **リミテッドカラー / ポスタリゼーション** | 2-3階調の平塗り。陰影を捨てるほど不気味になる | #3142 |
| **パネル分割(split panel montage)** | 同一画面に複数の断片を同時に置く(幾原邦彦の様式) | #3143 |
| **不気味の谷** | 目鼻の配置だけ正しく生気がない人形の顔 | #3143 |

### MADと相性が良い理由（3点）

1. **情報量が少なくリズムが高い** — 平面の形は拍で切っても壊れない。透視図法を維持しないので高速カットに耐える
2. **AIの不安定さが欠点にならない** — 「正しい解剖」が無いので破綻が破綻に見えない。揺らぎが味になる
3. **意味を宙吊りにできる** — 説明しないまま情緒だけ運べる。演出原則1(示唆で語る)と噛み合う

### 用途の割り当て（演出原則3「意味に紐づいたときだけ使う」の遵守）

| 技法 | カット | 紐づく意味 |
|---|---|---|
| **パネル分割** | C61-63(走馬灯) / C47(物量) | **一人が複数に割れている** = クララドールズと引き裂きの主題そのもの。装飾でなく主題の視覚化 |
| **リミテッド平塗り** | C30(魔獣の異変) | 生気の欠如。名簿の魔獣にある「顔のグリッチ」と地続き |
| **コラージュ / イヌカレー** | C54-55(ワルプルギス顕現) | 既定。魔女の領域 |
| **紐状の絡まり** | C44(糸が食い込む) / C59(糸が切れる) | 因果の糸 |

⚠ 使用時は `weak_reference` を明示し、同一性を担う参照とは**役割を分ける**(憲法第5条)。
