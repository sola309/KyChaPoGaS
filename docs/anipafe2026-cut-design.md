## C1（5.21s / 人物なし / 打点ゼロ）— 半月

**役割**: 作品の最初の一枚。**ほむらの権能の限界そのもの**を、説明せずに見せる。
3回現れる画(C1 → C31-32 → C67)の起点。

**画**: まっすぐに切られた月。右半分が存在しない。残った左半分は上から下まで完全な直線の縁で
終わり、そこだけが細く白く灼ける。欠けた側は影ではなく**空の黒**。
月の下には何も無い ── 地形も街も出さない。空だけ。

**示唆のために消したもの**: 「なぜ欠けているか」の一切。
月が欠けていることの**理由も、周囲の文脈も与えない**。観客はただ「何かがおかしい」とだけ思う。

**唯一の動き**: 光源のない影が、月の面をゆっくり横切る(全編モチーフの1回目)。
月は上書きされた表面、影を落としているのは下の実体(紋章石)。**初見では気づかせない**。
カメラは動かさない。5.2秒のうち動くのは影だけ。

**AI技術**: 使わない。ここは素の画力で見せ、技術は後半に取っておく。

**3回の変奏**:
| | 画 | 意味 |
|---|---|---|
| C1 | 半月＋横切る小さな影 | 何かがおかしい |
| C31-32 | 同じ月。影が画面の半分を覆う | 外側の存在が増大している |
| C67 | 上書きが剥がれ、**紋章石が現れる** | 彼女が触れられなかったものの正体 |

## C2（5.79s / 手だけ / キック1発）— 差し伸べる手と、糸の回収

**役割**: 叛逆のラストの象徴的再演。**全編を貫く「差し伸べる手」の1回目**。

**画**: 暗い空間に、桃色の糸に絡まれたダークオーブ。画面端から**手が一本**伸びる。
手は**届く前に光に飲まれる**。接触も消滅も見せない。
直後、糸が一斉に緩み、**糸巻きへ吸い込まれていく**。終盤に向けて加速。

**示唆のために消したもの**: **「触れる」瞬間と「消える」瞬間**。
原案は「触れて消滅」だったが、結果だけを見せる。何が起きたかは糸の動きが語る。

**手のモチーフの連鎖**（冒頭で観客に手を覚えさせることでC19が効く）:
C2 まどかの手が届かない → C18 ほむらの開いた手から光 → **C19 二人の手が鏡像で向き合う**
→ C50-53 まどかが弓を引く手 → C54 引き裂く

**打点**: 唯一のキック(1発)に「糸が一斉に緩む」瞬間を当てる。

**AI技術**: dissolution。ただし人物ではなく**糸の端**に使う。

## C3（9.17s / タイトル / スネア17）— 6つのロゴ＝シリーズの年表

**役割**: ビートが落ちる。作品の始動。**唯一の文字使用箇所**(他66カットは完全に文字禁止)。

**素材**: 公式ロゴ6点。**色の変遷がそのまま物語の転落**になっている。

| 順 | 作品 | asset | 色 |

| 2 | 劇場版[前編] 始まりの物語 | 2937 | 桃 |
| 3 | 劇場版[後編] 永遠の物語 | 2932 | 桃 |

| 5 | 帰巡の物語 | 2934 | 金 |

**割り付け**（2スネアに1枚。実測打点に基づく）:

| 時刻 | 打点 | 出来事 |
|---|---|---|
| 0.24 | スネア1 | TV版 |
| 1.40 | スネア3 | 前編 |
| 2.55 | スネア5 | 後編 |

| 7.16-8.90 | 加速する4発 | 廻天が残り、螺旋が収束してC4へ |

**画**: 宇宙空間が螺旋状にねじれる。ロゴはその中心に現れ、**次のロゴに上書きされて消える**
(前のロゴの残像が滲みながら次へ流れ込む = datamosh)。

**なぜこの技法か**: **「上書き」は本作の主題そのもの**。タイトルが主題の実演になる。
装飾のグリッチではなく、意味に紐づいた技術使用(原則3)。

**文字方針との整合**: これは装飾のタイポグラフィではなく、**公式ロゴによる年表の提示**。
67カット中ここだけを例外とし、他は完全禁止とすることで、**唯一の例外であること自体が効果**になる。
