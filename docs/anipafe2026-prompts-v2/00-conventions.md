# AniPAFE2026 生成単位プロンプト v2 — 規約

作成 2026-08-24。v1(`docs/anipafe2026-prompts/`)は比較用に凍結。以後の正はこちら。
根拠: `anipafe2026-rewrite-policy.md` + 参照集の構造分析(平均語/文 v1=20.4 → 参照主流=9-13)。

## v1からの構造変更(5点)

1. **短い命令文・1文=1イベント。** 文芸的な従属節を捨てる。目標: 平均12語/文以下
2. **冒頭に様式テーゼ**(`{{TH:*}}`)。作品の美学を1行目で宣言し、末尾の200語ブロックを廃止
3. **ショット境界を実測スネアに打つ。** MG主戦場=6〜9ショット / 中密度=3〜5 / 静=1〜2。
   時刻は `beat_map.txt` の実測値。ワイプ・パネル切替・窓の交代は**すべてショット境界**として書く
4. **LAWブロック**(005形式)。`{{BEATLAW}}`(全編共通)+単位固有の `A triggers B` 対応を大文字見出しで集約
5. **参照は画角ごと一致させる。** クローズアップには顔クロップを渡す。素材が無ければ
   `【要素材】`と明記して理想を書く(現素材に縛られない)

## プレースホルダ(v2追加分)

| タグ | 内容(~30語の短文) |
|---|---|
| `{{TH:PRO}}` | 序・終のテーゼ(黒・深紫・唯一のブルーム) |
| `{{TH:MEM}}` | 幕1(記憶の額縁) |
| `{{TH:CITY}}` | 偽街(菫の横光ノワール) |
| `{{TH:GOLD}}` | 黄金嵐変種(C18-24) |
| `{{TH:DAY}}` | 日常 |
| `{{TH:STORM}}` | 間奏 |
| `{{TH:A3}}` | 幕3(菫×血赤) |
| `{{TH:WATER}}` | 水面 |
| `{{BEATLAW}}` | BEAT LAW: ハードカットは必ずスネア上/キック=可視の衝撃/シンバル=可視の光と粒子/Never drift |
| `{{DP}}` | 深度面5-8枚の速度差(短縮版) |

キャラ定義(`{{HOMU_ID}}`等)はv1と同じ辞書を使い、**subject_definitionsにのみ**置く。
detailed_description内では `<Picture N>` ラベルか短いハンドルで指す(公式: canonical labels)。

## 単位フォーマット

```
## U## — C## 題 (モード / 生成Nf / 実尺 / ショット数)
参照(理想): <Picture N> #ID or 【要素材】説明 (役割)
MG: 技法=意味

subject_definitions: …(役割宣言+キャラ定義)
summary: …
retention_analysis: …
detailed_description: {{TH:*}}
[Shot 1] 短文。短文。短文。
[Shot 2] At 00:0X.XXX, …
…
BEAT LAW: {{BEATLAW}} 固有対応(A triggers B; …)
(固有LAWブロック — WINDOW LAW / WIPE LAW など必要時)
{{DP}} {{ST2}}
overall_soundscape: …
non_diegetic_music: N/A
```

I2VAはU01/U06/U10/U42のみ(3条件充足)。リップシンクはU13/U14(日本語)・U29/U30(英語)。
キュゥべえは口が動かない(憲法32条)。口の開きは1音節ぶん(37g)。

## 語数方針(v2の意図的な逸脱)

参照集の主流(002=366語/003=220語/004=269語)に合わせ、**dd展開後200-450語**を狙う。
公式のRef2VA目標(350-500語)より短い側に寄るが、これは「1文=1イベント」でイベント密度を
上げた結果であり、状態の水増しで埋めない。公式目標との差は**T1のA/Bで検証**する
(薄い単位に物理を足すのは結果を見てから)。

## 品質基準(このバージョンの10点)

- 曲が盛り上がるほど映像が強くなる(v1は逆だった)
- 全MGイベントがスネア実測時刻のショット境界に乗っている
- MG要素が光を受ける物体である(縁のスペキュラ・窓の内外で光が変わる)
- 盛り上げ5区間に連続量が割り当てられている
- 参照の画角=ショットの画角
