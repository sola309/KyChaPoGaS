## 共通の作法（C7で確立）

1. **窓の中身は歌詞が指すものにする**(MG言語辞書の規則)
2. **窓の縁は硬い線**。滲ませない。中身は縁を越えない
3. **Z順を作る** — 何かを人物の背後に置き、人物を暗くしない
4. **同心円の波紋を使わない**。広がるものは**枝分かれする流体**で
5. **MG要素は光を受ける物体**(縁がスペキュラを拾う・窓の内外で光の質が変わる)
6. **ショットは実測スネアの生値で切る**。MGイベント=ショット境界

## 注意

- C56/C57は方針書で「密な音に静止」としていた。**この指定で上書きされる**が、
  C54-55(最大密度)の直後という位置は変わらない。**静けさをMGで作る**方向で解く
  （動きを足すのではなく、層を増やす）
- C61-63は既にdatamosh/パネル分割を書いてあるが、**C7水準まで具体化する**必要がある
- 対象外のカット（C1/C2/C4/C5/C6/C43/C45/C65/C66/C67）は引き続き光が主役
