# 計画: 同一レイヤー内のクリップ重なりによるトランジション(2026-09-20 案・未実行)

## 目的
- 遷移のために下敷きレイヤー(Video 4)を使わず、1 本のレイヤー上でクリップを重ね、重なり区間をトランジション(クロス/白/黒 + カーブ + 不透明度)として扱う。
- 重なり区間をタイムライン上で可視化し、そこを操作して遷移を調整できるようにする。

## 現状(調査結果)
- UI/バックエンドとも、同一トラック上のクリップ重なりを禁止していない(重なり検出コードなし)。
- バックエンドの `_clamp_duration_to_cut` が「開始フレームから完全に覆える最後のカット終端」までにクリップ長を切るため、カット境界をまたぐ重なりが作れない。
- レンダラー: オーバーレイトラックは重なったクリップを両方合成(後のクリップが上)。ベーストラックは直列前提で、重なるとタイムラインがずれる。`transition_in` は後続クリップ側の設定で、cross は「前クリップ素材を延長して下に敷く」実装(2026-09-18 追加)。
- プレビュー: トラックごとに「現在フレームに掛かる最初のクリップ」だけを描画。重なった 2 本目は描かれない。

## 提案するモデル
- 遷移 = 同一トラック上で連続する A(前)と B(後)の重なり区間 `[B.start, A.end)`。重なり長がそのまま遷移長。
- B 側に保持: `transition_in`(cut/cross/white/black、既存)、`transition_frames`(重なり長と同期。UI ではクリップを重ねると自動更新)、新規 `transition_ease`(linear / ease-in-out / ease-in / ease-out)、新規 `transition_hold`(白/黒で「完全に色になる位置」0〜1、既定 0.5)。
- A の重なり部分は A の素材の続き(既存フレーム)を再生。B は重なり区間で不透明度 0→1(cross)、または A→色→B(white/black)。
- `fade_in_frames`/`fade_out_frames`/`opacity` は既存のまま併存(遷移とは独立の単純フェード)。

## 実装項目
1. バックエンド
   - モデル: `transition_ease`, `transition_hold` を Clip に追加(マイグレーション)。
   - クランプ: 後続クリップ B が `transition_in != ""` を持つ場合、A は `B.start + B.transition_frames - 1` まで伸ばせる(= 重なりだけ許可)。それ以外は現行どおりカット終端で切る。
   - レンダラー(オーバーレイ): 重なり区間で B の alpha をカーブに従ってランプ。white/black は A を色へフェードアウト → B を色からフェードイン(hold 位置で切替)。既存の「前クリップ素材を延長」方式は撤去し、明示的な重なりに一本化。
   - レンダラー(ベース): 重なりを xfade の duration にマップ(ベースは直列前提のため、A の重なり分を xfade で消費)。
2. プレビュー
   - トラックごとに現在フレームに掛かる全クリップ(通常 2 本)を開始順に描画。B の alpha はレンダラーと同じカーブ。
   - 各クリップに補助 <video>(クリップ ID キー)を持たせ、重なり中の 2 本を同時にシーク・描画。
3. タイムライン UI
   - 重なり区間を A の末尾/B の先頭に斜線バンドで表示し、長さ(f)をラベル表示。
   - 重なり区間をドラッグで伸縮(= B の開始か A の終端をトリム)。クリックで遷移種別・カーブ・hold を編集する小パネル。
   - インスペクタの「遷移」に ease/hold を追加。`transition_frames` は重なりと同期(手入力で変えたら B を動かさず A の終端を伸縮)。
4. 移行
   - C6 の現行配置(Video 4 下敷き + fade_in)を、Shots 1 本上の重なり(A 延長 + B cross)へ置き換える補助スクリプト。以後 Video 4 は不使用。

## リスク・注意
- 既存プロジェクトで意図せず重なっていたクリップは、これまで「後が上」だったのが「遷移なし(cut)」なら同じ見え方のまま(alpha ランプ無し)。互換性は維持。
- ベーストラックの重なりは xfade マップに限定(直列構造を維持)。
- クランプ緩和は「遷移を持つ B がある場合のみ」に限定し、生成物の尺超過が無制限にならないようにする。
