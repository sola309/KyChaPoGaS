### 2-3. 区間の時間の決まり(確認(実測))

「通常」版は 現在の区間番号 + 区間の中の割合 を AviUtl から受け取り、区間ごとに 開始値 → 終了値 を補間する(全体で 1 本ではない)。その割合の定義を完成版で確かめた:

- **最後の区間(中間点なしの 1 区間も同じ)**: 割合 = (コマ − 区間の頭)/(最後のコマ − 区間の頭)。**最後のコマで終了値に届く。**
  - 実測: シーン 38 のオブジェクト 5232(X 0 → 500・inCirc・4984〜5017)。完成版の各コマに最も近い取りこみ comp のコマは、5010〜5017 の 8 コマとも同じコマ(差 3〜6。隣のコマは 15〜37)。
    分母が 1 コマ長い読みなら最後のコマは 76% の位置(120 px 手前)になり、1 つ前のコマに近くなるはずだが、そうならなかった。
- **途中の区間**: 割合 = (コマ − 区間の頭)/(次の区間の頭 − 区間の頭)。**中間点の値に届くのは次の区間の先頭コマ。**
  - 実測: シーン 30 のオブジェクト 3933(X 2816 → 1613.6・inQuad・3754〜3774、次の区間は 3775 から)。3768〜3790 の 23 コマとも同じコマが最も近く、区間の変わり目(3774・3775)に段は無い。
- 取りこみ器(`Conv.scalar`)はこの決まりどおりにキーを打っていた。**直す所は無い。**
- 補足: Codex に調べさせた公開資料(再実装の記事)は「最後の区間も分母はコマ数(最後のコマで届かない)」と書いていたが、上の実測と合わない。実測を採った。
- 完成版のコマと aup のコマの対応は 完成版 = aup + 1(これまでの見比べと同じ)。

### 2-6. `@イージング.anm`(アニメーション効果の X・Y・Z・拡大率・透明度。81 個)

確認(本文):

- track0 = タイプ(1〜41)、track1 = 開始、track2 = 終了、track3 = 進捗 %(−1 = 自動)。設定: 元の値を無視する・インターバル(ms)・Back 係数・振れ幅・周期。
- 自動のときの割合は **オブジェクトの中のコマ番号 ÷ 総コマ数**。コマ番号は 0 から「総コマ数 − 1」までなので、**最後のコマでも終了値に届かない**(トラックバーとは決まりが違う)。
  総コマ数が「コマ数そのもの」であることは lua.txt の説明と公開の検証記事による(自分では測っていない。該当区間 1036〜1085 は花びらのトランジションに隠れて測れなかった)。
- 進捗を手で動かしているとき(48 個)は 割合 = 進捗/100。その進捗のトラック自体は 2-3 の決まりで動く。
- X・Y・Z・回転は元の値に足す(「元の値を無視する」のときだけ置き換え)。拡大率・透明度は**上書き**。
- インターバルは個別オブジェクト(文字ごとなど)の番号 × インターバル ぶん遅らせる。この作品は全部 0。

取りこみ器は終わりのキーを最後のコマに置いていた → 最後のコマ + 1 に直した(35 キー)。inCirc(タイプ 26)の群 14 個では、最後のコマの位置が 100% → 80% になる(= 1 コマぶん遅くなる)。
`X軸回転`・`Y軸回転`・`Z軸回転` の名前は取りこみ器の分岐に無い(この作品では未使用)。
